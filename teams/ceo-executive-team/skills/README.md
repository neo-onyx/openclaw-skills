# CEO / Executive Skills Pipeline

Strategy → board → investor relations → exec briefing.

## Pipeline

strategy_lead → board_prep_lead → investor_relations → exec_briefing

## Orchestrators

| Skill | Purpose |
|-------|---------|
| `/strategy_lead` | OKRs + intel + initiatives → handoff board_prep_lead |
| `/board_prep_lead` | Board deck + narrative + metrics → handoff investor_relations |
| `/investor_relations` | Investor update + Q&A + earnings → handoff exec_briefing |
| `/exec_briefing` | Exec summary + risk radar + triage (end) |
