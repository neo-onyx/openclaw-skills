# Skills index

Every orchestrator and worker skill in this repo. Use this to find a skill by name or to see what each team includes.

**Convention:** Slash commands use underscores (`/product_analyst`). Folder names use kebab-case (`product-analyst/`). Both refer to the same SKILL.md.

**Path in this repo:** `teams/<team-folder>/skills/<skill-folder>/SKILL.md`

## Finding a skill on disk

In this repo: **`teams/<team-folder>/skills/<skill-folder>/SKILL.md`**  
Example: `teams/fullstack-product-team/skills/product-analyst/SKILL.md`

The copy-all-skills script merges all skills into one flat `skills/` tree in your target workspace so an agent can resolve e.g. `/product_analyst` to `skills/product-analyst/SKILL.md`.
