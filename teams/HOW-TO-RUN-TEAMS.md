# How to use these teams

See the main doc: [../HOW-TO-RUN-TEAMS.md](../HOW-TO-RUN-TEAMS.md).

- **Add skills:** Run `./scripts/copy-all-skills.ps1` or `.sh` from repo root with your target `skills/` path.
- **Run a pipeline:** Invoke the entry-point skill (e.g. `/product_analyst`, `/financial_analyst`) with the right input.
- **Every skill:** [SKILLS-INDEX.md](SKILLS-INDEX.md)
